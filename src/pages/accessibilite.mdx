# Accessibilité et réglages

Ce site doit pouvoir être lu par **tous les élèves**, quelle que soit leur façon de lire ou d'utiliser un écran. Tu peux l'adapter à tout moment grâce au bouton **Réglages** en haut de chaque page (dans le menu sur téléphone).

<OpenSettingsButton />

## Ce que tu peux régler

| Réglage | À quoi ça sert |
| --- | --- |
| **Thème clair / sombre** | Le mode sombre fatigue moins les yeux le soir. Par défaut, le site suit le réglage de ton appareil. |
| **Contraste renforcé** | Textes en noir pur (ou blanc pur), bordures plus marquées, liens soulignés. |
| **Taille du texte** | De 100 % à 150 %, sans casser la mise en page. Le zoom du navigateur (<kbd>Ctrl</kbd> + <kbd>+</kbd>) fonctionne aussi. |
| **Police** | *Atkinson Hyperlegible* (par défaut, conçue pour distinguer facilement les lettres), *OpenDyslexic* (pensée pour les lecteurs dyslexiques) ou la police habituelle de ton appareil. |
| **Espacer le texte** | Plus d'espace entre les lignes, les mots et les lettres. |
| **Souligner tous les liens** | Pour repérer les liens sans se fier à la couleur. |
| **Réduire les animations** | Coupe les animations et les effets saisonniers. Activé automatiquement si ton appareil le demande. |
| **Thèmes saisonniers** | Flocons en hiver, chauves-souris à Halloween, π le 14 mars… Tu peux les désactiver. |

Tes choix sont enregistrés **uniquement dans ton navigateur** (rien n'est envoyé nulle part).

## Naviguer au clavier

- <kbd>Tab</kbd> / <kbd>Maj</kbd> + <kbd>Tab</kbd> : passer d'un élément à l'autre. L'élément actif est entouré d'un cadre bien visible.
- Le premier appui sur <kbd>Tab</kbd> propose **« Aller au contenu principal »** pour sauter le menu.
- <kbd>Échap</kbd> : fermer la fenêtre des réglages.

## Un problème ?

Si une page est difficile à lire ou à utiliser, parles-en en classe : on la corrigera.
