# Exercices Python

:::objectif
- Mobiliser les notions de variables, opérateurs et fonctions en Python
:::


:::exercice Appeler une fonction
Voici une fonction qui calcule l'aire d'un rectangle :

```python
def aire_rectangle(longueur: float, largeur: float) -> float:
    return longueur * largeur
```

Utilisez la fonction `aire_rectangle` pour calculer l'aire d'un rectangle de 10 cm de longueur et 5 cm de largeur.
:::

:::exercice Compléter la spécification d'une fonction
Voici une fonction qui calcule le périmètre d'un rectangle :

```python
def perimetre_rectangle(longueur, largeur):
    return 2 * (longueur + largeur)
```

Complétez la spécification de la fonction `perimetre_rectangle` pour respecter entièrement les bonnes pratiques.
:::

    # Complétez la fonction pour calculer le volume d'un cylindre

:::exercice Coder une fonction
Écrivez une fonction `division_euclidienne` qui prend deux entiers `a` et `b` en paramètres et qui correspond à l'exemple d'appel suivant.

```python
division_euclidienne(17, 5)
```
Cet appel affichera le résultat suivant :

```
"17 = 3 * 5 + 2"
```

:::

:::exercice Coder une fonction
Écrivez une fonction `imc` qui prend deux paramètres : le poids (en kg) et la taille (en m) d'une personne, et qui calcule l'indice de
masse corporelle (IMC) en utilisant la formule : $\text{IMC} = \frac{\text{poids}}{\text{taille}^2}$.

:::

:::exercice Coder une fonction
Écrivez une fonction `energie_cinetique` qui prend deux paramètres : la masse (en kg) et la vitesse (en m/s) d'un objet, et qui calcule
l'énergie cinétique en utilisant la formule : $\text{Energie cinétique} = \frac{1}{2} \times \text{masse} \times \text{vitesse}^2$.
:::
