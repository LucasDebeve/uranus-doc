# Sciences Numériques et Technologie

La **SNT** est un enseignement commun à tous les élèves de Seconde. L'objectif : comprendre le numérique qui nous entoure, ses usages, et prendre du recul sur son impact dans la société.

## Les 7 thèmes de l'année

| Thème | Ce qu'on y découvre |
| --- | --- |
| **Internet** | Comment les données voyagent d'un ordinateur à l'autre : adresses IP, paquets, protocoles. |
| **Le Web** | Ce qui se passe quand on ouvre une page : URL, HTML, CSS, moteurs de recherche. |
| **Les réseaux sociaux** | Leur fonctionnement, les graphes, la modération, l'identité numérique. |
| **Les données structurées** | Tables, formats (CSV…), métadonnées et traitement des données. |
| **Localisation, cartographie et mobilité** | GPS, cartes numériques, calcul d'itinéraires. |
| **Informatique embarquée et objets connectés** | Capteurs, actionneurs, et les systèmes qui les pilotent. |
| **La photographie numérique** | Pixels, couleurs, capteurs et traitement des images. |

:::info Les cours arrivent au fil de l'année

Les chapitres sont publiés ici au fur et à mesure de leur étude en classe. Ils apparaîtront dans le menu à gauche.

:::
